# منصة وصاب التعليمية العلمية

نسخة أولية مستقلة مستوحاة من مجموعة الوظائف العامة الظاهرة في موقع «الهائل - دفتر التحضير الذكي»، وليست نسخاً لكوده أو محتواه.

## الوحدات الموجودة

- لوحة تحكم وإحصائيات.
- تحضير درس جديد ومولد خطة.
- ربط الدرس بالواقع والموجه الشخصي والسبورة والدرس الصوتي والملخص والخريطة الذهنية وحل التقويم والعرض التقديمي.
- مكتبة الكتب.
- بنك الدروس والاختبارات.
- دفتر الدرجات والحضور.
- جدول الحصص.
- محرر الاختبارات: اختيار من متعدد، صح/خطأ، إجابة قصيرة.
- بوابة المعلم.
- بوابة الطالب.
- واجهة المصحح الذكي للصور.
- واجهة المنصة المدرسية المحلية.
- الخطة الفصلية.
- الاختبارات الشفوية والقرعة.
- التقييم الذاتي من 65 درجة.
- حل نماذج الاختبارات.
- النسخ الاحتياطي المحلي.
- PWA والعمل الأساسي دون اتصال.
- ربط اختياري مع Gemini API عند إضافة المفتاح من الإعدادات.
- الفصول السحابية والواجبات والتسليم والتصحيح الإلكتروني.

## التشغيل

يمكن فتح `index.html` مباشرة، والأفضل نشر المستودع كصفحة ويب حتى يعمل Service Worker وميزات PWA بصورة صحيحة.

## البناء

يتم البناء والنشر عبر GitHub Actions من فرع `main`، مع فحص JavaScript والتحقق من PWA بعد النشر.
